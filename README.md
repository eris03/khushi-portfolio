# Khushi Yadav — an interactive digital exhibition

A portfolio built as a storybook rather than a resume.

Next.js 14 (App Router) · TypeScript · Tailwind CSS · Framer Motion · GSAP · Lenis

## Run it

npm install
npm run dev

## The rooms

A watercolour preloader that paints the letter K into AI circuitry. A custom flower cursor. A hero with an animated illustration that leans toward your pointer. A flippable sketchbook. Floating islands. A skills galaxy. A gallery of paintings that move. An Art x AI split with a divider that follows your mouse. A metro line with a train that rides your scroll. A flip wall of certificates. Glass trophies. A night-mode contact form that folds your note into a paper plane. A moonlit lantern footer.

All content lives in lib/data.ts.
